# 🚀 Life Pressing

Life Pressing est une application de gestion de pressing développée avec Flutter et SQLite. Elle permet de gérer les clients, les vêtements, les commandes et les paiements de manière simple et efficace.

---

## ✨ Fonctionnalités

- 👤 Gestion des clients
- 👕 Gestion des vêtements
- 📦 Gestion des commandes
- 🧾 Gestion des détails des commandes
- 💳 Gestion des paiements
- 📄 Génération automatique de reçus PDF
- 📊 Tableau de bord avec statistiques
- 🔍 Recherche rapide des clients, vêtements, commandes et paiements

---

## 🛠️ Technologies utilisées

- Flutter
- Dart
- SQLite (sqflite)
- PDF
- Material Design 3

## 🚀 Installation

1. Cloner le projet

```bash
git clone https://github.com/ndouakacoupaulisrael-boop/life-pressing.git
```

2. Se placer dans le dossier

```bash
cd life-pressing
```

3. Installer les dépendances

```bash
flutter pub get
```

4. Lancer l'application

```bash
flutter run
```
